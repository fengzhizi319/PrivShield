# 发明专利草案目录

本目录汇总了基于 `PrivShield` 项目可申请的若干发明专利草案，共 **17 篇**（5 篇英文文件名 + 12 篇中文文件名）。每篇专利均包含**创新点提炼**与**专利原文（含权利要求书、摘要）**，可作为后续专利申报或技术交底书的参考。

> 说明：本文档内容为基于现有项目能力提炼的专利草案，需在正式申报前由专利代理人进行权利要求布局、新颖性/创造性检索与形式审查。

## 三、专利族布局建议

- **核心专利族**：已有专利 1（三层漏斗分类分级）+ 已有专利 4（Sidecar 隐私治理）可构成项目主线专利族。
- **机制补充专利**：新增专利 4（Mondrian K-匿名）、新增专利 5（mTLS 访问控制）与已有专利 2（规则引擎）、已有专利 3（DP 预算）共同构成纵深专利组合。
- **场景扩展专利**：新增专利 1（图像多模态打码）适用于医学影像、DICOM、病例图片场景；新增专利 3（LDP/机制自适应）适用于终端数据采集、联邦学习场景；新增专利 2（网关负载均衡）适用于多副本、大规模部署场景。
- **可信验证专利**：已有专利 5（预算链上记账与 ZKP 合规证明）与已有专利 6（处理可验证性与血缘链证明）构成区块链 + 零知识证明方向的专利族，与已有专利 3（HMAC 审计）、已有专利 4（Arrow 元数据）形成从“可信记账”到“可证处理”的递进布局。
- **脱敏治理专利**：已有专利 7（范畴化降级泛化与四柱强剥离抹平）聚焦高敏信息的差异化处置策略——与已有专利 2（分级层面的降级压制规则引擎）互补：专利 2 解决“等级如何降级裁定”，专利 7 解决“高敏内容如何降级保留或彻底抹平”；与已有专利 4（Sidecar 原语编排）配合，构成从识别、处置到编排的完整脱敏链路。
- **影像治理专利**：已有专利 8（多模态图像安全打码与文本-图像联动脱敏）聚焦医学影像/DICOM/病例图片的识别、VLM 语义分级、Fail-Closed 沙箱打码与图文策略联动——与已有专利 1（三层漏斗文本分类分级）互补：专利 1 解决“文本如何分级”，专利 8 解决“图像如何识别、分级与打码并与文本口径对齐”；是英文草案 patent_01 的中文完整申请书版本。
- **网关治理专利**：已有专利 10（双协议负载均衡与分布式预算一致性自愈）聚焦网关层双协议代理、事件循环感知调度、预算预扣池与崩溃自愈回滚——与已有专利 3（DP 预算记账本体）互补：专利 3 解决“预算如何记账与审计”，专利 10 解决“多实例网关层如何高并发预扣与失败自愈”；是英文草案 patent_02 的中文完整申请书版本。
- **跨域授权与仲裁专利族**：专利 9（防前端篡改乐观授权与违规仲裁）、专利 11（硬件根密钥多级衰减会话委托）与专利 12（零知识证明 + 乐观审计跨域隐私授权）构成终端授权链路的递进布局——专利 9 解决“所见即所签与越权事后可证”，专利 11 解决“高频调取免生物识别且权限单调衰减、泄露危害有界”，专利 12 解决“跨域匿名准入与合规开棺追责的统一”；三者与专利 5、6（链上记账与可证处理）共享 DA 存证与 ZKP 基础设施，形成从授权、委托到审计追责的完整闭环。

建议由专利代理人进一步进行权利要求拆分、新颖性/创造性检索与形式审查。
