# 专利草案 04：基于 Mondrian 多维分区与向量化优化的数据集级 K-匿名方法

## 一、创新点提炼（与已有专利的差异定位）

> 已有中文专利 4 已覆盖 Sidecar 架构下的 K-匿名泛化、自适应分段年龄泛化、人群差异化效用、隐私元数据随 Arrow 流转等。本专利草案聚焦于**数据集级 Mondrian 多维分区算法**、**数值型/分类型准标识符的统一泛化策略**、**Pandas 向量化优化与 Python List 平滑降级**、**严格 K-匿名保证与单记录启发式模式的双模式设计**，与已有专利 4 的自适应分段年龄泛化形成互补。

1. **数据集级 Mondrian 多维分区算法**
   - 将数据表视为多维空间，每条记录视为一个点，每个准标识符（QI）视为一个维度。
   - 递归选择跨度最大的维度，按中位数位置切分，并保证左右子分区记录数均不少于 k，从而严格满足 K-匿名。
   - 与单记录启发式泛化不同，本方法基于完整数据集进行全局优化，可验证每个等价组大小 ≥ k。

2. **数值型与分类型准标识符统一泛化**
   - 数值型 QI 输出区间泛化（如 `age=25` → `age=[25-30]`）。
   - 分类型 QI 输出取值集合泛化（如 `zipcode=100001` → `zipcode={100001,100002}`）。
   - 等价组内取值全部相同时保持原值，减少信息损失。
   - 非 QI 敏感字段原样保留，便于下游分析。

3. **Pandas 向量化优化与平滑降级**
   - 当输入为 pandas DataFrame 时，采用 Pandas 原生 `_mondrian_pd` 算法进行中位数排序拆分与等价区间泛化，避免行级 Dict 转换带来的序列化/反序列化开销。
   - 未安装 pandas 时平滑降级为基于 Python List 的 Mondrian 递归流程，保证核心逻辑在各种环境中可用。
   - 时间复杂度 O(n log² n)，适合中小规模批量数据发布。

4. **双模式设计：严格保证 vs 单记录启发式**
   - 数据集级模式：严格保证 K-匿名，适用于批量数据发布、数据共享、离线分析。
   - 单记录启发式模式：基于预定义泛化层次快速近似泛化，适用于实时流处理，但明确提示无统计保证。

5. **多格式输入与 SecretFlow 联邦适配**
   - 支持记录列表、pandas DataFrame、SecretFlow DataFrame 等多种输入。
   - 输出 pandas DataFrame 副本，便于下游分析。
   - 通过 `data_adapters.py` 提供统一 `to_records` / `from_records` 转换。

## 二、专利原文

### 发明名称

一种基于 Mondrian 多维分区与向量化优化的数据集级 K-匿名方法及系统

### 技术领域

本发明涉及数据安全技术领域，尤其涉及数据发布、数据共享、医疗/政务数据匿名化、K-匿名与信息损失控制。

### 背景技术

K-匿名是防止数据重识别的重要技术，要求发布的数据集中每条记录在准标识符属性上的取值组合至少与 k-1 条其他记录相同。现有技术存在以下问题：
1. 许多实时脱敏系统采用单记录启发式泛化，无法验证是否真正满足 K-匿名，容易导致过度泛化或泛化不足。
2. 传统 Mondrian 实现基于 Python List 逐行处理，在大规模数据下性能低下。
3. 缺乏对数值型与分类型准标识符的统一泛化策略。
4. 缺少与 DataFrame 生态（pandas、SecretFlow）的无缝集成。

### 发明内容

本发明提供一种基于 Mondrian 多维分区与向量化优化的数据集级 K-匿名方法及系统，通过全局数据集分析、中位数多维分区、Pandas 向量化实现与平滑降级，实现严格、高效、可扩展的 K-匿名处理。

一种基于 Mondrian 多维分区与向量化优化的数据集级 K-匿名方法，包括：
- 接收包含多条记录的数据集与准标识符列集合；
- 将每条记录视为多维空间中的点，每个准标识符列视为一个维度；
- 递归执行 Mondrian 多维分区：在当前分区内计算各 QI 维度的跨度，选择跨度最大的维度作为划分维度；按该维度对记录排序并选择中位数分割点；切分后保证左右子分区记录数均不少于 k；
- 当分区大小小于 2k、递归深度达到上限或无法安全切分时，对当前分区执行泛化：数值型 QI 输出区间泛化，分类型 QI 输出取值集合泛化，非 QI 敏感字段保持不变；
- 合并所有分区结果，输出满足 K-匿名的数据集；
- 当输入为 pandas DataFrame 时，采用 Pandas 原生向量化路径执行中位数排序与泛化；当 pandas 不可用时，降级为基于 Python List 的实现。

进一步地，所述维度跨度的计算包括：对数值型 QI 计算 max-min；对分类型 QI 计算不同取值数量减 1。

进一步地，所述中位数分割点的选择包括：将记录按划分维度排序后，取中间位置索引，并通过 `max(k, min(mid, n-k))` 约束保证两侧记录数均 ≥ k。

进一步地，所述泛化包括：
- 数值型 QI 泛化为 `[min-max]` 区间字符串；
- 分类型 QI 泛化为 `{v1, v2, ...}` 集合字符串；
- 当等价组内某 QI 取值全部相同时，保持原值以减少信息损失。

进一步地，还包括单记录启发式泛化模式，根据预定义泛化层次对单条记录进行近似泛化，用于实时流处理，并明确提示该模式不提供 K-匿名统计保证。

进一步地，还包括输入校验：校验 k ≥ 2、QI 列非空且存在于数据中、记录数 ≥ k；不满足时快速失败并给出清晰错误信息。

进一步地，还包括信息损失控制：通过 `max_depth` 参数限制递归深度，防止对高度偏斜数据过度泛化。

进一步地，还包括指标与日志：通过 `privacy_kano_operations_total` 计数器与结构化日志记录操作类型、数据集行数、等价组数量。

### 具体实施方式

**Mondrian 算法流程**
```
mondrian(records, qi_cols, k, depth):
    if len(records) < 2*k or depth <= 0:
        return generalize(records, qi_cols)

    dim = choose_dimension(records, qi_cols)
    split_idx = find_median_split(records, dim, k)

    if split_idx is None:
        return generalize(records, qi_cols)

    left = records[:split_idx]
    right = records[split_idx:]
    return mondrian(left, ...) + mondrian(right, ...)
```

**维度选择实施例**
- 对数值型 age：跨度 = max(age) - min(age)。
- 对分类型 zipcode：跨度 = 不同取值数 - 1。
- 选择跨度最大的维度作为划分维度。

**中位数切分实施例**
- 假设分区有 n=8 条记录，k=2。
- 排序后 mid = 8 // 2 = 4。
- split_idx = max(2, min(4, 6)) = 4。
- 左侧 4 条，右侧 4 条，均 ≥ 2k=4。

**泛化实施例**
- 数值型 age [25, 26, 27, 28] 泛化为 `[25-28]`。
- 分类型 zipcode {100001, 100002} 泛化为 `{100001,100002}`。
- 敏感字段 disease 保持原值。

**Pandas 向量化优化实施例**
- 输入为 pandas DataFrame 时，调用 `k_anonymize_dataframe(df, qi_cols, k, max_depth)`。
- `_mondrian_pd` 直接操作 DataFrame 列，利用 Pandas C 语言层面的排序与切片，避免 Python 级行迭代。
- 对大规模数据（如 10 万行）可提供数十倍加速。
- 若未安装 pandas，自动调用基于 List 的 `_mondrian_list`。

**数据集级 vs 单记录模式**
- 数据集级：必须提供完整数据集，严格保证 K-匿名，推荐用于批量发布。
- 单记录级：无需完整数据集，快速近似泛化，用于实时流处理，但需在日志中提示无统计保证。

### 摘要

本发明公开一种基于 Mondrian 多维分区与向量化优化的数据集级 K-匿名方法及系统。该方法将数据集记录视为多维空间点，递归选择跨度最大维度并按中位数切分，保证每个子分区不少于 k 条记录；当无法继续切分时对数值型准标识符做区间泛化、对分类型准标识符做集合泛化，从而严格满足 K-匿名。本发明还提供 Pandas 向量化快速路径与 Python List 降级路径的双实现，兼顾性能与兼容性，适用于批量数据发布、医疗数据共享等场景。
