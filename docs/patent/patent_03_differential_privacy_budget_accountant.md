# 专利草案 03：面向差分隐私的本地-中心式混合部署与机制自适应选择方法

## 一、创新点提炼（与已有专利的差异定位）

> 已有中文专利 3 已深入覆盖差分隐私预算记账的注册表工厂、SQLite 共享记账、时间窗口重置、HMAC 审计、RDP 会计、元数据侧信道防护、分布式无噪累加器等。本专利草案聚焦于**中心式 DP 与本地 DP（LDP）的混合部署架构**、**Laplace/Gaussian/解析高斯/离散拉普拉斯机制的自适应选择**、**自适应截断（Adaptive Clipping）**、**用户级 DP（User-Level DP）** 与 **整数格 ℤ 离散拉普拉斯机制**，与上述专利形成互补。

1. **中心式 DP 与本地 DP 混合部署**
   - 中心式 DP：用户将原始数据交给可信数据管理者，管理者在聚合结果上加噪声，噪声小、效用高。
   - 本地 DP（LDP）：每个用户在数据离开设备前通过随机响应等机制扰动，服务器只收到扰动值，无需信任服务器，但噪声大。
   - 本方法根据数据源信任模型、查询延迟要求、隐私参数要求，在同一个 Sidecar 中同时提供中心式 DP 与本地 DP 接口，并支持按数据源或查询类型选择部署模式。

2. **噪声机制自适应选择**
   - 支持 Laplace 机制（纯 ε-DP，无 δ）、Gaussian 机制（(ε, δ)-DP，适用于高维/组合）、解析高斯机制（Analytic Gaussian Mechanism，Balle & Wang 2018，对任意 ε>0、δ>0 数值求解最小 σ）。
   - 根据用户指定的 ε、δ、查询维度、敏感度类型（L1/L2）自动推荐或选择最优机制：
     - 要求 δ=0 或 ε 较小 → Laplace；
     - 高维向量查询、需要紧致组合界 → Gaussian；
     - 需要最优噪声尺度 → 解析高斯机制。

3. **自适应截断（Adaptive Clipping）**
   - 对 sum/mean 查询，通过自适应学习调整 clip 边界，避免 clip 边界过大导致噪声过大或边界过小导致数据截断损失。
   - 提供私有 clipping 参数搜索机制，在满足 DP 前提下逼近最优 clip 边界。

4. **用户级差分隐私（User-Level DP）**
   - 传统 DP 默认记录级（record-level）邻接关系，即相邻数据集相差一条记录。
   - 用户级 DP 将相邻数据集定义为相差一个用户的全部记录，通过按用户分组贡献裁剪（per-user contribution clipping）保护用户整体隐私，适用于一个用户贡献多条记录的场景（如多次就诊记录）。

5. **整数格 ℤ 上的离散拉普拉斯机制**
   - 对整数型聚合查询（如 count、直方图计数），使用离散拉普拉斯分布（Discrete Laplace）而非连续 Laplace，避免浮点噪声导致结果非整数。
   - 离散采样基于整数格，保证输出仍为整数，提升结果可用性与解释性。

6. **运算绑定的接口设计**
   - 强调 DP 必须绑定具体运算（count、sum、mean、histogram），每次查询针对单列数据并明确指定机制与参数。
   - 拒绝“给每条原始记录加噪声”的误区，区分中心式 DP、本地 DP 与启发式数据扰动。

## 二、专利原文

### 发明名称

一种面向差分隐私的本地-中心式混合部署与机制自适应选择方法及系统

### 技术领域

本发明涉及数据安全技术领域，尤其涉及差分隐私、本地差分隐私、隐私机制自适应选择、用户级隐私保护以及整数域噪声机制。

### 背景技术

差分隐私通过在查询结果上注入校准噪声提供可量化隐私保证。现有技术主要存在以下问题：
1. 中心式 DP 与本地 DP 通常作为独立系统实现，难以在同一个服务中根据数据信任模型灵活选择。
2. Laplace 与 Gaussian 机制的选择依赖人工判断，缺乏根据 ε、δ、维度、敏感度自动选择的机制。
3. 经典 Gaussian 机制要求 ε≤1 且噪声界松散，解析高斯机制虽可优化但未广泛集成。
4. sum/mean 查询的 clip 边界通常由调用方静态指定，难以自适应数据分布。
5. 记录级 DP 无法有效保护一个用户贡献多条记录的场景（如电子病历中同一患者多次就诊）。
6. 对整数聚合查询（如 count、直方图），连续 Laplace 噪声产生非整数结果，降低可用性。

### 发明内容

本发明提供一种面向差分隐私的本地-中心式混合部署与机制自适应选择方法及系统，通过统一接口支持中心式 DP 与本地 DP，根据查询特征自动选择噪声机制，并支持自适应截断、用户级 DP 与整数离散拉普拉斯机制。

一种面向差分隐私的本地-中心式混合部署与机制自适应选择方法，包括：
- 接收差分隐私查询请求，所述请求包含查询类型、目标数据、隐私参数（ε、δ）、部署模式偏好与机制偏好；
- 根据部署模式偏好与数据源信任模型选择中心式 DP 或本地 DP 模式；
- 在中心式 DP 模式下，根据查询类型确定敏感度，从数据中提取目标列并执行截断、聚合与加噪；
- 在本地 DP 模式下，对每个用户/记录在数据离开设备前通过随机响应或离散拉普拉斯机制进行扰动，服务器仅对扰动后的值执行聚合；
- 根据隐私参数、查询维度、敏感度类型与机制偏好，在 Laplace、Gaussian 与解析高斯机制中自适应选择最优机制；
- 对整数型聚合查询，采用整数格 ℤ 上的离散拉普拉斯机制，保证输出为整数；
- 对 sum/mean 查询，根据数据分布自适应学习 clip 边界；
- 对同一用户贡献多条记录的场景，按用户分组裁剪贡献并注入用户级 DP 噪声；
- 向聚合结果注入校准噪声并返回，同时在预算账本中记录隐私消耗。

进一步地，所述中心式 DP 与本地 DP 的选择包括：
- 当数据源受信任且追求高可用性时选择中心式 DP；
- 当服务器不可信或数据来自终端设备时选择本地 DP；
- 同一服务同时暴露两种模式的接口，按请求参数路由。

进一步地，所述机制自适应选择包括：
- 若 δ=0 或要求纯 ε-DP，选择 Laplace 机制；
- 若查询输出为高维向量或需要紧致组合界，选择 Gaussian 机制；
- 若需要最小噪声尺度且允许 δ>0，选择解析高斯机制并数值求解最小 σ；
- 对整数域查询，选择离散拉普拉斯机制。

进一步地，所述解析高斯机制通过二分查找数值求解满足 (ε, δ)-DP 的最小 σ，适用于任意 ε>0、δ>0，且噪声通常小于经典 Gaussian 公式。

进一步地，所述自适应截断包括：
- 对目标列执行分位数估计（满足 DP）以估计数据分布；
- 基于估计分布调整 clip 上下界，使大部分数据不被截断同时控制敏感度；
- 将 clip 边界搜索过程本身消耗的隐私预算计入总预算。

进一步地，所述用户级 DP 包括：
- 按用户标识分组，计算每个用户对聚合结果的贡献；
- 对每个用户的贡献进行 L1 或 L2 范数裁剪；
- 根据裁剪后的用户级敏感度注入噪声，满足相邻数据集相差一个用户的用户级 DP。

进一步地，所述整数离散拉普拉斯机制包括：
- 对计数或直方图查询，以参数 α 从离散拉普拉斯分布采样整数噪声；
- 概率质量函数为 `P(X=k) ∝ exp(-α |k|)`，其中 α = ε / Δf；
- 输出为整数，避免连续噪声带来的非整数结果。

进一步地，所述 mean 查询拆分为 count 与 sum 两个独立 DP 查询，分别加噪后相除，总预算按组合定理累加；当加噪后的 count 低于阈值时返回安全 fallback 值，防止分母发散。

进一步地，还包括统一数据适配器，支持 pandas、NumPy、PyArrow、Polars、SecretFlow VDataFrame/HDataFrame 作为输入。

### 具体实施方式

**中心式 DP 实施例**
- 用户请求：对 `salary` 列做 sum，ε=1.0，δ=1e-6，机制自适应。
- 系统选择解析高斯机制（因为 δ>0，需要最小噪声）。
- 用户未提供 clip 边界，系统启动自适应截断流程：先用 DP 分位数估计 salary 的 95% 分位数，得到 clip_upper=100000；然后执行 sum 查询。
- 敏感度 Δf = 100000 - 0 = 100000；解析高斯 σ 数值求解；注入噪声；返回结果并记录预算。

**本地 DP 实施例**
- 用户请求：对终端设备收集的是否患有高血压（0/1）进行频率估计，ε=2.0，LDP 模式。
- 每个设备执行二值随机响应：以概率 p = e^ε / (1 + e^ε) 保持原值，以 1-p 翻转。
- 服务器收集扰动后的值，使用纠偏估计量计算真实频率。

**机制自适应选择实施例**
- 查询类型：count，ε=0.5，δ=0 → 选择 Laplace 机制，b = 1/0.5 = 2。
- 查询类型：高维直方图（100 维），ε=1.0，δ=1e-6 → 选择 Gaussian 机制，利用高级组合定理获得更紧致界。
- 查询类型：sum，ε=2.0，δ=1e-6，需要最小噪声 → 选择解析高斯机制，σ 小于经典公式。
- 查询类型：count，要求输出整数，ε=1.0 → 选择离散拉普拉斯机制，噪声为整数。

**用户级 DP 实施例**
- 数据集包含同一患者的多次就诊记录，用户标识为 `patient_id`。
- 查询：患者总医疗费用的 sum。
- 按 `patient_id` 分组，对每个患者的总费用进行 L2 裁剪（clip_per_user=500000）。
- 用户级敏感度 = clip_per_user；注入 Laplace 或 Gaussian 噪声。

**自适应截断实施例**
- 对 salary 列执行 DP 分位数估计：消耗 ε_q=0.1 预算，得到 95% 分位数 C=98000。
- 设置 clip_upper = C，clip_lower = 0。
- 后续 sum 查询消耗 ε_s=0.9；总消耗 ε = 0.1 + 0.9 = 1.0。

### 摘要

本发明公开一种面向差分隐私的本地-中心式混合部署与机制自适应选择方法及系统。该方法在同一个服务中同时支持中心式差分隐私与本地差分隐私，根据数据源信任模型与查询特征自动选择部署模式；根据 ε、δ、维度、敏感度自适应选择 Laplace、Gaussian、解析高斯或离散拉普拉斯机制；对 sum/mean 查询执行自适应截断；对同一用户贡献多条记录的场景提供用户级差分隐私；对整数聚合查询采用整数格离散拉普拉斯机制保证输出整数。本发明提升了差分隐私服务的灵活性、数据效用与安全性，适用于医疗、金融、终端数据采集等隐私计算场景。
